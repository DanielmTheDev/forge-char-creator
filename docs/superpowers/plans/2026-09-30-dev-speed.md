# Dev Speed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the char-creator Playwright full run from ~16 min to ~5–6 min, make it green (no known-red noise), and remove the friction points hit during the feature-builder work (2026-09-29).

**Architecture:** Shared test helpers + a worker-scoped logged-in page fixture replace the per-spec boot/login. Test residue is swept at run start. The two chronic reds (Omega combat, overtime) are fixed or isolated. A committed probe script gives a 1-command "run JS in live Foundry" loop. Tiered npm test commands. A prebuilt icon index removes the ~17 s cold icon-picker load.

**Tech Stack:** Playwright (@playwright/test 1.60), Foundry V13.351 server (local, `FoundryData/`), dnd5e 5.2.5, midi-qol 13.0.63, node 25 (`node --test`).

**Spec:** none separate — the source is the analysis in the 2026-09-29 session, reproduced under "Background" below. Rulings made without a spec are provisional; record them in the ledger.

## Background (why each task exists)
Measured on 2026-09-29/30 (full run = `npx playwright test`, 16 specs, ~14–16.5 min):
1. `module.spec` runs the native T0 suite (`scripts/tests/index.js` `runAll()`), whose LAST test, `#testCombatEngineIntegration` ("Omega Combat Simulator", `scripts/tests/index.js:1246`, registered at `:49`), hangs at `Combat.create` or destroys the page context → the spec burns its 300 s timeout every run and marks the whole native suite red even when 19/19 other checks pass.
2. Every spec does its own goto → login → wait `game.ready` → sleep (30–60 s each).
3. Boot/login/notification code is copy-pasted in all 11 spec files; a notification fix had to be applied in 6 places, twice.
4. `playwright.config.js` sets `use.viewport: 1440x900`, but the project spreads `devices['Desktop Chrome']` AFTER it → viewport silently becomes 1280x720 → Foundry shows a permanent "resolution too low" notification that intercepts clicks at the top of windows.
5. The test world `ishait` (disposable test world) accumulates residue: ~20 "Aura Test Bot" actors, "Test Midi Damage"/"Overtime Poison E2E" items in the `forge-char-creator.forge-features` pack, stray "Overtime Attacker/Defender E2E" tokens on the active scene.
6. `tests/overtime.spec.js:338` calls `pack.deleteDocument(...)` — removed in v13 → spec always red.
7. Debugging via a throwaway probe script (login headless, `page.evaluate(code)`, print result) found two real bugs in minutes; currently it lives only in `~/Downloads/claude-tmp/probe/`.
8. No tiered test commands: only `npm run unit` (1 s) and the full suite.
9. Icon picker's first open indexes core `icons/` via ~500 single-directory `FilePicker.browse` calls (~17 s, server-bound; no recursive listing in v13). Persisted after that, but every fresh Playwright browser pays it.
10. Process overhead (spec + plan docs + final review) is heavy for small tasks.

## Global Constraints
- Work on a branch: `git checkout -b chore/dev-speed` (never commit straight to main; user merges/pushes).
- Foundry server: start `node FoundryVTT-Linux-13.351/resources/app/main.js --dataPath=$PWD/FoundryData` (background, log to `~/Downloads/claude-tmp/foundry.log`); one server per dataPath (lock). Check with `pgrep -f "[m]ain.js --dataPath"`. Stop with `kill $(pgrep -f "[m]ain.js --dataPath")`. **NEVER `pkill -f Foundry` / `pkill -f playwright`** — the pattern matches your own shell and kills it (exit 144).
- Full Playwright runs take >10 min: run them with `run_in_background: true` (the Bash tool's foreground limit is 10 min) or `timeout 2400`, redirect output to `~/Downloads/claude-tmp/<name>.txt`, read the tail.
- Scratch/temp files → `~/Downloads/claude-tmp/` only.
- Commits: conventional subject, concise, NO attribution/co-author trailers. Never commit a file containing `TOCLAUDE`.
- Do NOT change `playwright.content.config.js` or anything under `forge-content/verify/` unless a task says so: those files are in the content gate's ENGINE hash (`forge-content/verify/stale.mjs`) — touching them forces a full `content:verify` re-sweep (xvfb + Foundry, several minutes). If you do touch them, run `npm run content:verify -- --full` before finishing.
- Keep every existing assertion's intent. Don't weaken asserts to make things green; if something is truly unfixable, `test.fixme()` it with a reason and a TODO.md entry.
- Record a before/after timing for the full run in the ledger and final report.

## Review Focus
1. **Shared page state leaking between tests** (open windows, user targets, active combats, changed settings) once tests share one logged-in page → expect each test to start clean (fixture teardown closes forge apps, clears targets, deletes flagged combats).
2. **A test that reloads or destroys the page** (combat/scene tests) poisoning every later test on the shared page → expect the fixture to detect a dead/reloaded page and re-login.
3. **Residue sweep deleting real content** → only names/flags created by tests; never touch non-test actors/items.
4. **Prebuilt icon index for the wrong Foundry version** → fall back to live indexing when the version doesn't match.
5. **Probe script leaving the browser/process running on timeout** → always close the browser; exit non-zero on timeout.

```js
// Shared Playwright helpers for the forge-char-creator suite.
export const BASE = `http://localhost:${process.env.FOUNDRY_PORT ?? 30000}`;

export async function makeNotificationsClickThrough(page) {
  // Headless has no GPU: Foundry pins permanent warnings over the top of the screen
  // (and may add more later) — make them click-through instead of removing them once.
  await page.addStyleTag({ content: "#notifications, #notifications * { pointer-events: none !important; }" });
}

export async function bootFoundry(page) {
  await page.goto(BASE);
  if (page.url().includes('/setup')) {
    await page.evaluate(async () => {
      await fetch('/setup', { method: 'POST', headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ action: 'launchWorld', world: 'ishait' }) });
    });
    await page.waitForTimeout(2000);
    await page.goto(`${BASE}/join`);
  }
  await page.waitForSelector('select[name="userid"]', { timeout: 15000 });
  await page.selectOption('select[name="userid"]', { label: 'Gamemaster' });
  await page.click('button[name="join"]');
  await page.waitForNavigation({ timeout: 20000 });
  await page.waitForSelector('#ui-middle', { timeout: 30000 });
  await page.waitForFunction(() => globalThis.game?.ready === true, null, { timeout: 60000 });
  await makeNotificationsClickThrough(page);
  await page.waitForTimeout(2000); // module/midi hooks attach
}

export async function closeForgeApps(page) {
  await page.evaluate(() => {
    for (const a of [...foundry.applications.instances.values()]) if (a.id?.startsWith("forge-")) a.close();
  }).catch(() => {});
}

export async function openBuilder(page, initialState = {}) {
  await page.evaluate(async (s) => {
    const { EffectCreatorApp } = await import("./modules/forge-char-creator/scripts/effect-creator.js");
    await new EffectCreatorApp({}, s).render(true);
  }, initialState);
  await page.waitForSelector('.forge-effect-creator .fc-step.active');
  return page.locator('.forge-effect-creator');
}

export async function openWizard(page) {
  await page.evaluate(async () => {
    const { CharCreatorApp } = await import("./modules/forge-char-creator/scripts/app.js");
    await new CharCreatorApp().render({ force: true });
  });
  await page.waitForSelector('#forge-char-creator-app .fc-step.active');
  return page.locator('#forge-char-creator-app');
}

export function pipeConsole(page, re = /SMOKE/) {
  page.on('console', m => { const t = m.text(); if (re.test(t)) console.log(`[Foundry] ${t}`); });
}
```

**Produces:** `npm run dev:eval -- '<js expression or async IIFE>'` or `npm run dev:eval -- path/to/file.js` → prints `RESULT <json>` and exits 0; exits 1 on error; exits 2 on timeout (default 60 s, `EVAL_TIMEOUT` env ms). - [ ] Write `scripts/dev/eval.mjs`:
```js
// Run JS inside the live local Foundry as the GM and print the result.
// Usage: npm run dev:eval -- 'game.actors.size'   |   npm run dev:eval -- ./probe.js
// Server must be running. EVAL_TIMEOUT (ms, default 60000), EVAL_LOG (regex, default SMOKE|Error).
import { chromium } from 'playwright';
import { readFileSync, existsSync } from 'node:fs';

const arg = process.argv[2];
if (!arg) { console.error("usage: npm run dev:eval -- '<js>' | <file.js>"); process.exit(1); }
const code = arg.endsWith('.js') && existsSync(arg) ? readFileSync(arg, 'utf8') : arg;
const timeout = Number(process.env.EVAL_TIMEOUT ?? 60000);
const logRe = new RegExp(process.env.EVAL_LOG ?? 'SMOKE|Error');
const base = `http://localhost:${process.env.FOUNDRY_PORT ?? 30000}`;

const browser = await chromium.launch();
let exit = 0;
try {
  const page = await browser.newPage({ viewport: { width: 1440, height: 900 } });
  page.on('console', m => { const t = m.text(); if (logRe.test(t)) console.log('[F]', t.slice(0, 400)); });
  await page.goto(base);
  await page.waitForSelector('select[name="userid"]', { timeout: 15000 });
  await page.selectOption('select[name="userid"]', { label: 'Gamemaster' });
  await page.click('button[name="join"]');
  await page.waitForFunction(() => globalThis.game?.ready === true, null, { timeout: 90000 });
  const r = await Promise.race([
    page.evaluate(code).then(v => ({ v })),
    new Promise(res => setTimeout(() => res({ timeout: true }), timeout))
  ]);
  if (r.timeout) { console.log('RESULT TIMEOUT'); exit = 2; }
  else console.log('RESULT', JSON.stringify(r.v, null, 1));
} catch (e) {
  console.log('ERROR', e.message); exit = 1;
} finally {
  await browser.close();
}
process.exit(exit);
```

```js
import { test as base, expect } from '@playwright/test';
import { bootFoundry, closeForgeApps, makeNotificationsClickThrough } from './foundry.js';

// One logged-in GM page per worker (workers: 1 → one login per run).
export const test = base.extend({
  gmPageHolder: [async ({ browser }, use) => {
    const context = await browser.newContext({ viewport: { width: 1440, height: 900 } });
    const holder = { page: await context.newPage() };
    await bootFoundry(holder.page);
    await use(holder);
    await context.close();
  }, { scope: 'worker' }],

  // Per test: hand out the shared page; re-login if a previous test killed or reloaded it; clean up after.
  gmPage: async ({ gmPageHolder }, use) => {
    const alive = await gmPageHolder.page.evaluate(() => globalThis.game?.ready === true).catch(() => false);
    if (!alive) {
      if (gmPageHolder.page.isClosed()) gmPageHolder.page = await gmPageHolder.page.context().newPage();
      await bootFoundry(gmPageHolder.page);
    }
    await use(gmPageHolder.page);
    await closeForgeApps(gmPageHolder.page);
    await gmPageHolder.page.evaluate(() => {
      for (const t of [...(game.user.targets ?? [])]) t.setTarget(false, { releaseOthers: false });
    }).catch(() => {});
  },
});
export { expect };
```
